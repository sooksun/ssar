# มุมมองการประเมินครูผู้ช่วย

เพิ่มเข้ามาเป็น**มุมมองการประเมินอีกแบบหนึ่ง** ในระบบ โดยไม่กระทบการทำงานของระบบเดิม (ปฐมวัย / ขั้นพื้นฐาน)  
อ้างอิงจากเอกสารอ้างอิง:

- **docref/doc_ref2.pdf** — แนวทางประเมินครูผู้ช่วย
- **docref/doc_ref6.pdf** — ตารางสรุปตัวชี้วัดการเตรียมความพร้อมและพัฒนาอย่างเข้ม (ครูผู้ช่วย)

---

## โครงสร้างตัวชี้วัด (จาก doc_ref6)

### 1. ด้านวิชาชีพ (มี 2 ส่วนหลัก รวม 10 รายการ) — ประเมินทั้ง 4 ครั้ง

| ส่วน | รายการ | รหัสตัวชี้วัด |
|------|--------|----------------|
| การจัดการเรียนรู้ | การวิเคราะห์หลักสูตร | 1.1 |
| | การออกแบบการจัดการเรียนรู้ | 1.2 |
| | การจัดกิจกรรมการเรียนรู้ | 1.3 |
| | การเลือกและใช้สื่อ เทคโนโลยี | 1.4 |
| | การวัดและประเมินผล | 1.5 |
| | การจัดบรรยากาศ | 1.6 |
| | การใช้เทคโนโลยีดิจิทัล | 1.7 |
| การส่งเสริมสนับสนุน | การจัดทำข้อมูลสารสนเทศ | 2.1 |
| | ระบบดูแลช่วยเหลือผู้เรียน | 2.2 |
| | กฎหมายและระเบียบปฏิบัติ | 2.3 |

### 2. ด้านสังคม (2 รายการ) — เน้นครั้งที่ 3–4

- 3.1 การเรียนรู้จากกัลยาณมิตร (Mentor/ครูพี่เลี้ยง)
- 3.2 การเรียนรู้เป็นเครือข่าย (PLC)

### 3. ด้านคุณลักษณะส่วนบุคคล

- **ส่วนที่ 1:** วินัย คุณธรรม จริยธรรม (ตัวชี้วัด 4 — 11 พฤติกรรมบ่งชี้)
- **ส่วนที่ 2:** การพัฒนาตนเอง — 5.1 ภาษาไทยและอังกฤษ, 5.2 เทคโนโลยีดิจิทัล, 5.3 การเงิน, 5.4 สุขภาพ

## การใช้ในระบบ

- **ระดับ (EduLevel):** `ASSISTANT_TEACHER` — ชื่อแสดง: **การประเมินครูผู้ช่วย**
- หน้า **หลักฐาน** (`/evidence`) และ **รายงานความพร้อม** (`/reports/readiness`) มีแท็บ **ครูผู้ช่วย** ให้เลือกมุมมองนี้
- การบันทึกหลักฐาน เลือกระดับ **ครูผู้ช่วย** แล้วเลือกมาตรฐาน/ตัวชี้วัดตามด้านด้านบน
- ข้อมูล seed อยู่ใน `prisma/seed-data.ts` (มาตรฐาน ตัวชี้วัด ตัวชี้วัดย่อย) — รัน `npm run db:seed` หลังเพิ่ม level ใหม่

---

## เกณฑ์การผ่าน (สรุปจากเอกสาร)

- **ครั้งที่ 1–2:** ด้านวิชาชีพ ≥ 9 รายการ, ด้านคุณลักษณะส่วนบุคคล (วินัยฯ) ≥ 7 รายการ  
- **ครั้งที่ 3–4:** ด้านวิชาชีพ ≥ 11 รายการ, ด้านสังคม ≥ 3 รายการ, ด้านคุณลักษณะส่วนบุคคล ≥ 11 รายการ
